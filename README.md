# Smart EV Charging Slot Booking System

## Project Description
The Smart EV Charging Slot Booking System is a Java desktop application developed to manage electric vehicle charging stations, chargers, and booking operations. It provides separate user and administrator interfaces.

## Technologies Used
- Java
- JavaFX
- MySQL
- JDBC
- MySQL Connector/J
- ZXing QR Code Library

## Features
- User registration and login
- Administrator authentication
- Station management
- Charger management
- Charging slot booking
- Booking history
- User profile
- Wallet and wallet transaction management

## Database
Database name: `ev_charging_db`

Tables:
- users
- stations
- chargers
- bookings
- wallets
- wallet_transactions

Database export: `database/ev_charging_db.sql`

## Project Requirements
- JDK 26
- JavaFX SDK 27
- MySQL Server
- MySQL Connector/J 9.5.0
- ZXing libraries

## Project Structure
- `src/` – Java source code
- `database/` – MySQL database export
- `screenshots/` – Application screenshots
- `lib/` – Required external libraries

## Execution
1. Install JDK, JavaFX SDK, and MySQL.
2. Create the database using `database/ev_charging_db.sql`.
3. Configure the database connection in the project.
4. Ensure the required libraries are available.
5. Compile and run the Java application.
